# 落地页规格（spec）

> 本文件先于代码。任何与本文件冲突的实现都算 bug；要改行为，先改这里。

## 1. 目标

给小程序「我的MBTI人格」做一个**Web 落地页**，用途单一：

**让第一次来的人，在 30 秒内明白这是什么、凭什么信、下一步点哪里。**

不是产品本体。产品本体是微信小程序（`xingge-app-kuikly/miniApp`）。
落地页只负责「说明 + 引流到小程序码」。

非目标（明确不做）：

- 不做在线答题（答题在小程序里，Web 只做说明与跳转）
- 不做登录、支付、会员、用户数据收集
- 不做社区、关系解析等未上线功能的入口
- 不引入构建工具、框架、npm 依赖

## 2. 约束

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 技术 | 纯静态：HTML + CSS + 原生 JS | 一个文件丢到任何静态托管就能跑；无构建即无维护 |
| 依赖 | 零运行时依赖 | 断网可看（除字体无外链） |
| 数据 | 由 `tools/build_data.py` 从源仓库生成 | DRY：16 型文案/配色/题库不在本仓库二次抄写 |
| 打开方式 | 支持 `file://` 直接双击打开 | 评审、内测不需要起服务器 |
| 视觉 | Apple Design Guide：大留白、层级靠字号与字重、克制的色彩、克制的动效 | 见 §6 |
| 语言 | 简体中文 | 产品面向中文用户 |

## 3. 数据来源（唯一真源）

| 数据 | 源文件 | 字段 |
| --- | --- | --- |
| 16 型基础信息 | `xingge-app-kuikly/shared/src/commonMain/assets/common/result.json` | `type` `summary` `color` `impressionSoft*` `impressionSpicy*` `description` |
| 16 型六维工作画像 | `.../app/mbti/data/json/ProfileData.kt`（内嵌 JSON） | `nick` `role` `group` `rank` `overall` `scores` `top` `low` |
| 题库与维度 | `xingge-app-kuikly/shared/src/commonMain/assets/common/tiku.json` | `testInfo` |
| 小程序码 | `.../assets/common/mbti/poster-qr.png` | 图片 |

`build_data.py` 只读不写源仓库，产物落在 `assets/data/personalities.js`。
源文件缺失或结构变化时，脚本**必须报错退出**，不允许静默降级成空页面。

## 4. 页面结构

单页，锚点导航。顺序即说服顺序：

| # | 区块 | 回答的问题 | 关键内容 |
| --- | --- | --- | --- |
| 1 | Hero | 这是什么？ | 一句话定位 + 主 CTA + 十六型色块墙 |
| 2 | 四个维度 | 测的到底是什么？ | EI / SN / TF / JP，各 7 题，共 28 题 |
| 3 | 十六型图鉴 | 我能对上号吗？ | 16 张卡（我的字·温柔版/毒舌版）+ 分组筛选 + 展开详情 |
| 4 | 报告样例 | 测完给我什么？ | 六维工作画像雷达图，可切换 16 型 |
| 5 | 怎么测 | 要花多久？ | 3 步，28 题约 3 分钟 |
| 6 | 常见问题 | 我在犹豫什么？ | 4 条：准不准 / 会不会被贴标签 / 要不要钱 / 隐私 |
| 7 | 尾 CTA | 下一步？ | 小程序码 + 提示 |

CTA 落地物统一为**小程序码**（`poster-qr.png`）。不放假下载按钮、不假造 App Store 链接。

## 5. 交互

- 图鉴卡片：点击展开/收起详情（`aria-expanded`），支持键盘 Enter/Space。
- 分组筛选：全部 / 分析家 / 外交官 / 守护者 / 探险家。
- 详情里的「温柔版 / 毒舌版」语气切换，对应 `impressionSoft*` / `impressionSpicy*`。
- 报告样例：切换类型 → 雷达图重绘（SVG）。
- 所有交互在无 JS 时降级为**可读**：卡片详情默认渲染在页面里，JS 只负责收起。

## 6. 视觉与无障碍

- 字体：系统栈（`-apple-system` / `PingFang SC` / `Noto Sans SC`），不引外链字体。
- 层级：正文 16–17px / 行高 1.7；小标题 20–24px；区块标题 32–44px；Hero 52–72px。
- 间距：区块垂直 96–128px，卡片内 20–28px，8px 栅格。
- 配色：以 16 型主色为点缀，正文用中性色；**深色型色**（如 `#22223B`）不得直接作浅底上的文字色，
  构建时统一换算 `text`（对白底 ≥4.5:1）与 `tint`（浅底）两个派生色。
- 深色模式：`prefers-color-scheme` 跟随系统。
- 动效：只做入场淡入上移，`prefers-reduced-motion: reduce` 时全部关闭。
- 焦点：可见焦点环；触控目标 ≥44px。
- 文案：不用「诊断」「治疗」「心理测评」等医疗词；页面底部常驻免责声明。

## 7. 自动验证（`tools/verify.py`）

必须全部通过才算交付：

1. 数据完整性：16 型齐全、四组各 4 型、六维每型 6 个分数且 0–100、rank 1–16 唯一、颜色合法。
2. 数据一致性：生成物与源仓库逐字段一致（重新生成后无 diff）。
3. HTML 结构：所有锚点导航目标存在、`id` 唯一、无空 `href="#"`。
4. 资源引用：`<img>`/`<link>`/`<script>` 指向的文件全部存在。
5. 文案红线：不出现「诊断」「治疗」「包治」「100% 准」等词。
6. 无障碍基础：每个 `<img>` 有 `alt`、每个交互元素可聚焦。

## 8. 验收方式

`python3 tools/verify.py` 全绿 + 无头浏览器在 1440 / 390 两个宽度截图人工过一眼 + `file://` 双击可开。

## 9. 已定项

- 站点品牌名 = 小程序正式名「我的MBTI人格」（人类 2026-10-26 确认）。
  品牌名不写死在页面里：`build_data.py` 从源仓库
  `xingge-app-kuikly/miniApp/dist/app.json` 的 `navigationBarTitleText` 读取，
  改小程序名后重跑脚本即可，页面与小程序不会名字不一致。
